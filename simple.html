Projects

Vezapp Planner Built at Vezapp · Working

Production planning for foundries

Problem: Foundries plan monthly dispatches in Excel and only find out an order will be late when it is already late.

What I did: Built a web app that plans each month's dispatches against real machine capacity, shifts and holidays. Planners upload the schedule from Excel. Each order is converted into moulds, cores, metal and machine minutes using the part's rejection rate. What-if planning lets them block a machine or add overtime and see which orders move.

Result: Shows every order's expected dispatch date and the bottleneck machine. Has reports (dispatch performance, utilisation, plan vs actual) with PDF/Excel export, an AI assistant for questions about the plan, and separate logins per company with Admin/Planner/Viewer roles.

Tools: Django · Next.js · PostgreSQL · Claude API · built with Claude Code

Fixing slow client dashboards Vezapp · Case study

Why Looker Studio was loading slowly

Problem: Client Looker Studio dashboards were loading very slowly.

What I did: Checked what was running on the MySQL server. The same heavy queries were firing many times at once, key tables had no indexes, and Looker caching was off.

Result: Recommended adding indexes, enabling Looker caching and reducing duplicate queries.

Tools: MySQL (AWS RDS) · Looker Studio
